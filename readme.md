### Stack tech

- Symfony : 7.4
- PHP : 8.2
- NODE : 22
- TS : 5.9


### Installation


Lancer `make init` pour récupérer l'environnement docker et charger la BDD.

- Accéder au serveur : https://localhost:8443/
- Accéder à la BDD : http://localhost:8080/


**Vérifier votre uid de user, si ce n'est pas 1000, il faut modifier le Dockerfile pour que vous puissiez lancer la config Docker !**
